# COVID-19 Data Exploration | SQL

## Project Overview
An SQL data exploration project analysing global COVID-19 data including 
infection rates, death percentages, and vaccination progress across countries 
and continents.

## Objective
- Explore global COVID-19 case and death trends
- Calculate death percentage and infection rates by country
- Analyse vaccination rollout vs population
- Create views for further visualisation

## Tools Used
- Microsoft SQL Server (SSMS)
- SQL (Joins, CTEs, Window Functions, Aggregate Functions)

## Data Source
Our World in Data — COVID Deaths Dataset
(https://ourworldindata.org/covid-deaths)

## Key SQL Concepts Used
- Joins
- CTEs (Common Table Expressions)
- Window Functions
- Aggregate Functions
- Creating Views
- Data Type Conversions

## Skills Demonstrated
- SQL data exploration and analysis
- Writing complex queries
- Data preparation for visualisation
